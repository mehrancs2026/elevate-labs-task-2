# TaskFlow - To-Do List Web App

**Plan less. Accomplish more.**

TaskFlow is a simple and responsive To-Do List Web Application built using HTML, CSS, and Vanilla JavaScript.

It allows users to manage daily tasks through a clean and easy-to-use interface.

## Live Demo

https://mehrancs2026.github.io/elevate-labs-task-2/

## Features

- Add new tasks.
- Mark tasks as completed.
- Delete tasks.
- Add tasks using the Enter key.
- Display a warning when the input is empty.
- Responsive design for desktop and mobile devices.
- Instant updates without refreshing the page.

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
